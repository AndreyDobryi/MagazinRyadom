МАГАЗИН РЯДОМ — ВЕРСИЯ 1.4

Что изменено:
- Вместо Leaflet/WebView используется нативный MapLibre Native Android 13.7.1 (OpenGL backend).
- Карта отображает растровые тайлы OpenStreetMap и маркеры найденных мест.
- Поиск и подсказки при вводе используют Photon (данные OpenStreetMap).
- Подсказки запрашиваются с задержкой, чтобы не перегружать публичный сервер.
- Ручное добавление магазина преобразует адрес в координаты через Photon и сохраняет запись на телефоне.
- Получение местоположения больше не подменяется старым lastLocation: приложение принимает только свежую точку.
- Выбор магазина обновляет виджет и не открывает маршрут автоматически.
- Пеший маршрут открывается отдельной кнопкой после выбора магазина.

Сборка:
1. В GitHub открой репозиторий MagazinRyadom.
2. Замени файлы проекта содержимым этого архива, сохранив структуру папок.
3. Сделай commit/push в ветку main.
4. Открой Actions и дождись завершения Build Android APK.
5. Если сборка зелёная, открой её и скачай Artifact MagazinRyadom-APK.
6. Распакуй artifact и установи app-debug.apk на Android.

Важно:
- Это исходный проект, а не готовый APK. Полную Android-сборку необходимо подтвердить через GitHub Actions.
- Photon — публичный поисковый сервер. Он допускает умеренное использование, но не гарантирует бесперебойную работу; частые запросы могут ограничиваться. Поиск зависит от полноты данных OpenStreetMap.
- Публичные тайлы OpenStreetMap предоставляются без SLA. Не использовать массовую загрузку/предзагрузку тайлов; соблюдать правила сервиса и сохранять видимую атрибуцию © OpenStreetMap contributors.
- OpenStreetMap — не полный каталог всех магазинов. Некоторые организации могут отсутствовать или иметь неполные адреса.
- Для ручного добавления указывай полный адрес, включая город. Запись сохраняется локально на этом телефоне.
- При приблизительной геолокации Android точность координат будет ниже. Для точного определения разреши приложению точное местоположение и включи службы геолокации.


Версия 1.4.4 — исправления геолокации и подсказок:
- Подсказки названий магазинов работают независимо от GPS.
- Добавлена ручная установка своего места по городу или адресу.
- Ручное место сохраняется между запусками приложения.
- Кнопка «Моё место (GPS)» позволяет вернуться к автоматическим координатам.
- Если GPS показывает неправильную точку, используйте «Указать моё место вручную».

Важно: ручное место задаётся по адресу через OpenStreetMap/Photon; точность зависит от полноты адресной базы.
