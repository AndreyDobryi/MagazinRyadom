МАГАЗИН РЯДОМ — ВЕРСИЯ 1.4

Что изменено:
- Вместо Leaflet/WebView используется нативный MapLibre Native Android 13.7.1 (OpenGL backend).
- Карта отображает растровые тайлы OpenStreetMap и маркеры найденных мест.
- Поиск и подсказки при вводе используют Photon (данные OpenStreetMap).
- Подсказки запрашиваются с задержкой, чтобы не перегружать публичный сервер.
- Ручное добавление магазина преобразует адрес в координаты через Photon и сохраняет запись на телефоне.
- Получение местоположения больше не подменяется старым lastLocation: приложение принимает только свежую точку.
- Выбор магазина обновляет виджет и не открывает маршрут автоматически.
- Пеший маршрут открывается отдельной кнопкой после выбора магазина.

Сборка:
1. В GitHub открой репозиторий MagazinRyadom.
2. Замени файлы проекта содержимым этого архива, сохранив структуру папок.
3. Сделай commit/push в ветку main.
4. Открой Actions и дождись завершения Build Android APK.
5. Если сборка зелёная, открой её и скачай Artifact MagazinRyadom-APK.
6. Распакуй artifact и установи app-debug.apk на Android.

Важно:
- Это исходный проект, а не готовый APK. Полную Android-сборку необходимо подтвердить через GitHub Actions.
- Photon — публичный поисковый сервер. Он допускает умеренное использование, но не гарантирует бесперебойную работу; частые запросы могут ограничиваться. Поиск зависит от полноты данных OpenStreetMap.
- Публичные тайлы OpenStreetMap предоставляются без SLA. Не использовать массовую загрузку/предзагрузку тайлов; соблюдать правила сервиса и сохранять видимую атрибуцию © OpenStreetMap contributors.
- OpenStreetMap — не полный каталог всех магазинов. Некоторые организации могут отсутствовать или иметь неполные адреса.
- Для ручного добавления указывай полный адрес, включая город. Запись сохраняется локально на этом телефоне.
- При приблизительной геолокации Android точность координат будет ниже. Для точного определения разреши приложению точное местоположение и включи службы геолокации.


Версия 1.4.4 — исправления геолокации и подсказок:
- Подсказки названий магазинов работают независимо от GPS.
- Добавлена ручная установка своего места по городу или адресу.
- Ручное место сохраняется между запусками приложения.
- Кнопка «Моё место (GPS)» позволяет вернуться к автоматическим координатам.
- Если GPS показывает неправильную точку, используйте «Указать моё место вручную».

Важно: ручное место задаётся по адресу через OpenStreetMap/Photon; точность зависит от полноты адресной базы.


ВЕРСИЯ 1.5.0 — карта и ближайшая точка:
- Увеличена высота карты в приложении до 300 dp.
- Увеличена мини-карта Android-виджета до 132 dp.
- После поиска результаты сортируются по расстоянию по прямой; первая (ближайшая по координатам) точка выбирается автоматически.
- Для выбранной точки запрашивается пешеходный маршрут у публичного OSM foot-router; маршрут рисуется зелёной линией на карте.
- Камера карты подстраивается под весь маршрут.
- Поиск и маршрут доступны для обычных магазинов и общественных точек; некоторые категории и конкретные запросы, связанные с продажей алкоголя, ограничены.

Ограничения версии 1.5.0:
- Автовыбор ближайшей точки основан на расстоянии по прямой, а не на сравнении пеших маршрутов для каждого результата.
- Публичный пеший маршрутизатор может быть временно недоступен или ограничивать частоту запросов. В таком случае зелёная линия не появится; кнопка маршрута по-прежнему открывает внешнюю страницу OpenStreetMap.
- Это не голосовая turn-by-turn навигация и не фоновое постоянное сопровождение.
- Полную сборку APK нужно проверить в GitHub Actions; локальная Android-сборка в этой среде не запускалась.


Версия 1.5.1 — исправление локального поиска
- Сначала ищет совпадения по названиям объектов OpenStreetMap в радиусе 5 км от текущего местоположения.
- Если локальный поиск недоступен или не дал результатов, использует Photon с увеличенным лимитом и отсекает точки дальше 5 км.
- Ближайшая точка выбирается сортировкой по расстоянию от текущих координат.
- Если рядом нет совпадений, приложение не должно выбирать далёкую точку за пределами радиуса.
- Полнота результатов зависит от данных OpenStreetMap в конкретном районе.


Версия 1.6.0
- Переработан главный экран: тёмная тема, золотые акценты, отдельная панель поиска, более крупная карта и карточки результатов.
- Карта в приложении поддерживает перемещение, масштабирование, поворот и наклон.
- При открытом приложении GPS обновляется автоматически. Если пользователь переместился примерно на 25 метров, приложение запрашивает новый пеший маршрут; повторный запрос ограничен интервалом.
- Мини-карта виджета обновляется после выбора точки и после перестроения маршрута. Нажатие на виджет открывает приложение.
- Отслеживание работает, пока приложение открыто на экране. После сворачивания приложения обновления приостанавливаются; фонового сервиса в этой версии нет.
- Поиск алкогольных магазинов и целевых запросов к сети «Красное & Белое» не поддерживается.
