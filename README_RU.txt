МАГАЗИН РЯДОМ — Android-проект, версия 1.0 (MVP)

Что реализовано:
- тёмный интерфейс;
- выбор продуктовой сети из списка;
- запрос разрешения на геолокацию;
- получение текущего/последнего местоположения;
- поиск ближайшей отмеченной точки в OpenStreetMap через Overpass API;
- расчёт расстояния;
- открытие точки в установленном картографическом приложении;
- компактный виджет с названием выбранной сети и последним найденным расстоянием.

Поддерживаемые сети в списке: Пятёрочка, Магнит, Перекрёсток, Лента, Дикси, Lidl, Aldi, REWE, EDEKA.

ВАЖНЫЕ ОГРАНИЧЕНИЯ:
1. Результаты зависят от того, насколько полно магазины нанесены на OpenStreetMap.
2. Поиск выполняется при нажатии кнопки в приложении. Виджет показывает последний результат; он не отслеживает GPS непрерывно.
3. Android ограничивает частые фоновые обновления ради батареи. Периодическое обновление самого виджета системой не означает повторный GPS-поиск.
4. Для маршрута требуется приложение карт, установленное на телефоне.
5. Для поиска нужен интернет и разрешение на местоположение.

СБОРКА APK В ANDROID STUDIO:
1. Установи Android Studio на компьютер.
2. Открой папку проекта MagazinRyadom.
3. Дождись синхронизации Gradle и установки Android SDK 35.
4. Выбери Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

АВТОСБОРКА ЧЕРЕЗ GITHUB ACTIONS:
В проект добавлен файл .github/workflows/build-apk.yml. После загрузки проекта в GitHub можно открыть Actions, запустить Build Android APK и скачать артефакт MagazinRyadom-debug-apk.

Это исходный проект. APK в этом окружении не собран и не проверен на физическом устройстве.
