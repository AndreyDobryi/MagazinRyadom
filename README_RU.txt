МАГАЗИН РЯДОМ 1.2

Что добавлено: карта OpenStreetMap внутри приложения; поиск по названию и категориям; поиск через несколько публичных Overpass-серверов с POST-запросами; ручное добавление магазина по названию и адресу; сохранение пользовательских магазинов на телефоне; выбор магазина для виджета с названием, адресом, расстоянием и статичной мини-картой; открытие пешего маршрута.

Ограничения: карта и поиск требуют интернет; OpenStreetMap может не содержать конкретный магазин или адрес; публичные серверы могут временно ограничивать запросы; виджетная мини-карта статичная и обновляется после выбора магазина. Ручное добавление использует Nominatim для преобразования адреса в координаты.

Загрузка: замени файлы в корне GitHub-репозитория файлами из этого проекта, сохранив папки. Дождись зелёной галочки в Actions, скачай Artifact MagazinRyadom-APK, распакуй и установи app-debug.apk. Чтобы добавить свой магазин: кнопка «Добавить магазин вручную», введи название и полный адрес, сохрани.

Это исходный проект, не готовый APK. Сборка выполняется через GitHub Actions. Код нужно проверить на реальном устройстве после сборки.
