МАГАЗИН РЯДОМ 1.1 — ИНСТРУКЦИЯ

Что есть в проекте:
- поиск магазинов по названию;
- поиск по нескольким категориям (продукты, аптеки, одежда, обувь, электроника, зоотовары, косметика);
- сортировка найденных мест по расстоянию;
- выбор конкретной точки и открытие пешего маршрута;
- Android-виджет с названием, адресом, расстоянием и мини-картой;
- запрос точного местоположения с резервной попыткой получить последнюю известную позицию.

Ограничения:
- данные берутся из OpenStreetMap через Overpass API; не каждый магазин там отмечен, а адрес может отсутствовать;
- мини-карта в виджете — статичный снимок, создаваемый при выборе магазина; это не пошаговая навигация;
- виджет обновляется после выбора магазина в приложении. Для нового местоположения открой приложение и нажми «Обновить местоположение», затем выполни поиск и выбери точку;
- публичный сервер Overpass и сервер тайлов OSM могут временно ограничивать запросы.

Сборка через GitHub:
1. Загрузи все файлы и папки проекта в корень репозитория.
2. Убедись, что workflow находится в .github/workflows/blank.yml.
3. Открой Actions и дождись зелёной галочки.
4. Внизу успешного запуска скачай Artifact MagazinRyadom-APK.
5. Распакуй архив — внутри будет app-debug.apk.

Важно:
- Этот ZIP содержит исходный Android-проект, а не готовый APK.
- APK нужно собрать через GitHub Actions или Android Studio.
- Для виджета: зажми пустое место рабочего стола → Виджеты → Магазин рядом.
